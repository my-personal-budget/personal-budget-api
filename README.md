
# Personal Budget API

## Project Overview

Simple API to manage and track personal budgets
The API uses sqlite for storage

## Requirements

- Go 1.25.1
- Modules listed in `go.mod`
- sqlite3
- A c compiler in the PATH

## Getting Started

If not installed, install sqlite 
``` bash
brew install sqlite3
```

To run the project locally, use the development script:

```bash
sh scripts/dev.sh
```

this will start a air and run the project with live reloading
